# 2027 개정 실습 자료

2026년 10월 19일 반영 사항입니다.

- 원고와 같은 3개 장의 체계로 안내를 정리하고 비어 있던 링크와 없는 폴더 안내를 없앴습니다.
- NumPy·pandas·시각화 노트북을 저장소에 추가했습니다. 원고의 인덱싱·인덱스 병합·결측값 처리·히스토그램 빈도·Jointplot 제목 여백 등 수정된 코드를 반영했습니다.
- 현재 폴더 전체를 삭제하던 준비 명령과 반복 글꼴 캐시 삭제를 제거했습니다. 저장된 이전 출력은 비우고 실제 실행 결과를 확인하도록 했습니다.
- 브로드캐스팅, loc·iloc, 키 병합, 원핫 열 구조, 출력층·손실함수, 학습 곡선의 개념도를 추가했습니다.
- category 성능 실험과 긴 중간 출력은 추가 자료로 옮겼습니다.
- 회귀 신경망의 합성 입력 생성·학습·로그·곡선 재현 코드를 공개했습니다. 원래 부동산 실습자료의 결과와 구분합니다.

노트북의 재실행 결과와 패키지 버전은 실행 환경에 따라 달라질 수 있습니다. 시간이나 특정 모델의 성능 순위를 고정된 정답으로 사용하지 않습니다.

## 원고 말투와 실행 화면 보완

처음 원고처럼 개념의 이유와 코드의 역할을 차근차근 설명하도록 문장을 다시 다듬었습니다. 제1장의 긴 코드 나열은 실제 노트북 실행 화면으로 바꾸고, 공식 출제범위 화면도 추가했습니다. [실행 화면과 예제](screenshots.md)를 함께 볼 수 있습니다.


## 종이책 원고 반영

4쪽에 공식 KT 로고 캡처를 넣고 5쪽 공식 출제범위는 표 부분이 읽히도록 다시 캡처했습니다. 인쇄 원고에서는 외부 링크와 온라인 보충 설명 안내를 제거하고 필요한 계산과 짧은 예제를 본문에 반영했습니다. [실습과 이미지 보관 내역](print_edition.md)은 원고 밖의 관리 자료입니다.
