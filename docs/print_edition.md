# 종이책 원고의 실습과 이미지

2027년 개정 원고는 종이책에서 설명을 이어 읽을 수 있도록 정리했습니다. 본문에 외부 하이퍼링크나 깃허브 안내를 넣지 않으며, 출처는 기관명·자료명·확인일로 적습니다. API 요청 코드 안의 URL 문자열은 실행에 필요한 코드이므로 유지합니다.

책의 메서드 체이닝 해설에는 중간 결과를 확인하는 방법을, 표본 분산 해설에는 편차 제곱합을 n-1로 나누는 계산을 넣었습니다. category의 메모리 비교도 작은 예제로 책 안에서 실행합니다. [같은 실행 코드](../scripts/category_memory_example.py)를 이 저장소에도 보관합니다.

4쪽의 KT 로고는 [KT Corporate Identity](https://corp.kt.com/html/intro/design/ci.html) 공식 화면에서 로고 부분을 캡처했습니다. 5쪽의 표는 [AICE Associate 소개](https://aice.study/info/aice/asso) 공식 화면의 출제범위 부분입니다. 2026년 10월 19일 캡처했으며 픽셀을 덧그리거나 UI를 재구성하지 않았습니다. 아래 인쇄용 이미지는 실제 화면에서 해당 부분만 자른 것입니다.

| 자료 | 원본 화면 | 인쇄용 부분 캡처 |
|---|---|---|
| KT 공식 로고 | [원본](../assets/screenshots/kt_ci_official.jpg) | [부분 캡처](../assets/screenshots/print/kt_ci_print.png) |
| AICE Associate 출제범위 | [원본](../assets/screenshots/aice_scope_official.jpg) | [부분 캡처](../assets/screenshots/print/aice_scope_print.png) |

이 저장소의 링크는 자료 관리와 재현을 위한 것입니다. 인쇄 원고에는 링크를 넣지 않습니다.
